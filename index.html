WireGuard Windows installation

Non-admin account — Windows 10/11 PRO

  1. Add registry value from PowerShell:

    powershell
    New-ItemProperty "hklm:\software\wireguard" -Name "LimitedOperatorUI" -Value 1 -PropertyType "DWord" -Force

  2. Add your user to the group Network Configuration Operators. From PowerShell run:

    powershell
    Add-LocalGroupMember -Group "Network Configuration Operators" -Member "$username"

Non-admin account — Windows 10/11 HOME

  1. Download psexec from the Sysinternals page, or install it with Chocolatey:

    powershell
    choco install psexec

  2. Download nco.reg.

  3. Open an administrator console and type:

    cmd
    psexec -i -s regedit

  4. Choose File → Import and select the nco.reg file.

  5. Add your user to the group from PowerShell:

    powershell
    Add-LocalGroupMember -Group "Network Configuration Operators" -Member "$username"
    Or from the GUI: run control userpasswords2, choose the user you need and the group “Network Configuration Operators”.

  6. Add registry value from PowerShell:

    powershell
    New-ItemProperty "hklm:\software\wireguard" -Name "LimitedOperatorUI" -Value 1 -PropertyType "DWord" -Force
